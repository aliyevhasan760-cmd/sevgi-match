# SevgiMatch – Premium Tanışlıq Tətbiqi

**SevgiMatch** – müasir, qara və tünd qırmızı premium dizayna malik, real vaxtda işləyən tanışlıq tətbiqi və idarəetmə panelidir. Layihə Node.js/Express backend, Supabase (Authentication, PostgreSQL, Realtime, Storage) və təmiz HTML5/CSS3/JavaScript üzərində qurulub.

## 🚀 Əsas Xüsusiyyətlər
- **Supabase Authentication:** Təhlükəsiz qeydiyyat və giriş sistemi.
- **Profil Şəkli Yükləmə:** İstifadəçilərin şəkillərini real vaxtda yükləməsi.
- **Tanışlıq & Eşləşmə:** Profil kartları və bəyənmə sistemi.
- **Real-time Çat:** Anlıq mesajlaşma imkanı.
- **Premium Dizayn:** #080808 fon və #E50935 qırmızı vurğular.
